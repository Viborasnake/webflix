Actúa como Lead Product Designer, Design Systems Designer y especialista en accesibilidad digital. Crea en Figma Make un sistema de diseño móvil completo, profesional, escalable y documentado para una plataforma ficticia de streaming llamada **Webflix**.

No diseñes solamente pantallas independientes. Construye una biblioteca visual coherente basada en variables, estilos, componentes reutilizables, propiedades, variantes y patrones de interfaz.

El sistema debe estar preparado para diseñar posteriormente un experimento Wizard of Oz que busca validar si una selección breve de gustos durante el onboarding permite entregar recomendaciones iniciales más relevantes a usuarios nuevos.

## 1. Objetivo del sistema

Crear un Design System que permita construir de manera consistente:

* Onboarding de personalización.
* Selección de preferencias mediante swipe.
* Confirmación de gustos.
* Transición de procesamiento.
* Inicio personalizado de streaming.
* Filas horizontales de contenido.
* Vista de detalle.
* Reproductor simulado.
* Encuestas y mensajes posteriores a la reproducción.

El sistema debe sentirse:

* Cinematográfico.
* Inmersivo.
* Futurista.
* Tecnológico.
* Premium.
* Accesible.
* Claro y fácil de usar.
* Diferente de Netflix y de otras plataformas existentes.

No copies la marca, el color rojo, la “N”, la tipografía, las tarjetas ni las composiciones exactas de Netflix.

Diseña el sistema principalmente para aplicaciones móviles.

**Accessibility Guidelines**

* Contraste mínimo de texto.
* Contraste de componentes.
* Focus visible.
* Orden de navegación.
* Áreas táctiles mínimas de 44 × 44 px.
* Uso de etiquetas accesibles.
* Texto alternativo para imágenes.
* Uso correcto de encabezados.
* Alternativas a gestos.
* Estados no dependientes exclusivamente del color.
* Compatibilidad con `prefers-reduced-motion`.

* Uso de scrims y degradados.

Los botones “Pasar” y “Me gusta” deben estar siempre disponibles como alternativa accesible.

## 23. Dirección fotográfica

Documenta el estilo fotográfico por categoría:

* Comedia: expresiones alegres, escenas espontáneas y luz vibrante.
* Acción: movimiento, velocidad y alto contraste.
* Misterio: iluminación noir, sombras y ambientes urbanos.
* Ciencia ficción: tecnología, paisajes espaciales y luces frías.
* Drama: primeros planos emocionales e iluminación íntima.
* Romance: tonos cálidos y escenas cercanas.
* Documentales: imágenes auténticas, personas reales y naturaleza.
* Familiar: escenas luminosas, acogedoras y coloridas.
* Anime: ilustración dinámica y estilizada.
* Reality: escenarios llamativos y energía visual.
* Internacional: ciudades, culturas y ambientes reconocibles.
* Terror: tensión y atmósferas oscuras sin contenido explícito.

Usa fotografías distintas para cada preferencia.

No utilices la misma imagen cambiando únicamente el filtro.

El resultado debe parecer un sistema de diseño real preparado para un equipo de producto.

Debe incluir:

* Variables coherentes.
* Tokens semánticos.
* Auto Layout.
* Component properties.
* Variants.
* Boolean properties.
* Text properties.
* Instance swap.
* Estados interactivos.

* Ejemplos de accesibilidad.

Asegúrate de que todos los templates utilicen instancias de los componentes maestros.

* Registro.
* Pagos.
* Planes.
* Buscador.
* Descargas.
* Perfiles múltiples.
* Configuración avanzada.

Entrega un Design System visualmente consistente, editable, escalable y preparado para construir el prototipo completo de Webflix en Figma.
